## Projeto anterior

Mapa interativo do Parque Estadual Serra dos Martírios/Andorinhas (PESAM), desenvolvido para visualização e análise de dados geoespaciais.

O projeto usava Leaflet.js, HTML, CSS e JavaScript, com camadas e dados geográficos do IDEFLOR-Bio. Os dados públicos eram disponibilizados sob licença Creative Commons CC BY 4.0.
