Sobre o Projeto

PESAM - Mapa Interativo

Este mapa interativo foi desenvolvido para apresentar os dados geoespaciais do Parque Estadual Serra dos Martírios/Andorinhas (PESAM), localizado no município de São Geraldo do Araguaia, Pará.

Funcionalidades

  • Visualização de múltiplas camadas de dados geoespaciais
  • Alternância entre diferentes mapas base (satélite, ruas, etc.)
  • Exportação de dados em formato KML
  • Exploração de fotos de campo com geolocalização
  • Ferramentas de navegação e medição
